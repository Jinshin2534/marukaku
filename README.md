# まるかく (marukaku)

指一本でフリーハンドの円を描くと、真円度を採点するブラウザゲーム。

**公開**: https://marukaku.vercel.app

## しくみ

- 描いた線を弧長で等間隔に取り直し（描く速さで点の密度が偏るのを消す）、**最小二乗で円を当てはめる**（Kåsa 法の代数解 → 幾何距離の Gauss–Newton）。
- 採点は 2 つに分ける。
  - **半径のばらつき**: 半径方向の残差の RMS ÷ 半径。10% で 50 点（`100/(1+(x/0.1)²)`）。
  - **描き始めと終わりのずれ**: 始点–終点の距離 ÷ 半径。25% で 50 点。一周を超えたぶんは切り落とす。
  - 合計 = 75% ＋ 25%。裾の重い曲線なので、いびつでも 0 点にはならず、上位では差が出る。
- 半径の残差の 2 倍周波数成分が強いときは「楕円ぎみ（縦長/横長/斜め）」、そうでなければいちばん外れた方向を「◯時」で示す。
- 描く速さを一周 24 区間に分けてグラフにし、自己ベストのときの速さと重ねる。6 回以上描くと、自分の履歴から「速さのむら・所要時間と点の相関」を出す。
- 一周の 3/4 未満・小さすぎ・往復の多い線には点をつけない。

## 開発

```sh
pnpm install
pnpm dev     # http://localhost:5910
pnpm test    # Vitest
pnpm build
```

- 中核ロジックは `src/lib/`（純粋関数、合成した円・楕円でテスト）。描画は `src/render.js`、配線は `src/main.js`。
- `window.__app` でヘッドレス検証できる: `__app.submit(points)`、`__app.synth({...})`、`__app.demo()`、`__app.state`。
- 右上の「合成デモ」は合成した軌跡を自動で描く（記録には残さない）。
